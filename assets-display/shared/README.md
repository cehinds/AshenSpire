# Shared art

This game-owned folder retains the shared index. Companion export icons live in
`AI-Art/common/assets-display/shared/` on branch `ashenspire` and load from the
verified common release cache. [library.json](library.json) also groups UI,
cards, portraits, fonts, audio and other shared assets from pinned packs.
See [display art maintenance](../README.md).
