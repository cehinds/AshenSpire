# Ashen core adapter pack

This is the first executable configuration adapter, not a completed portable engine. Confirmed class attributes, deck role counts, hand rule, unlock order, route constraints and rest services are encoded as requested. provisionalPolicies.json enumerates temporary adapter policies for unresolved behavior; card balance, class-special effects and derived starting HP remain provisional. Current profile delegates to the original source runtime unchanged. Edit these source JSON files and run node tools/game-config.mjs build; generated JS and locks are derived artifacts.
