# Multi-hit (`status.multiHit`)
Each stack repeats the holder's attack once more: 1 stack makes 1 attack into 2. 1 stack expires each turn.
- Carried by: statuses on any entity.
- Lives in: `src/model/gearEffects.js` (`GearStatusRules`).
- Portability: legacy (service.json is empty until the behaviour moves to catalog ops).
