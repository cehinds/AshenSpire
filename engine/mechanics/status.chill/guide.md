# Chill (`status.chill`)
Each stack: -5% damage dealt. Every 3 stacks, its next turn starts with 1 less Stamina. One stack wears off each turn.
- Carried by: statuses on any entity.
- Lives in: `src/engine/elementIdentity.js` (`ElementReceiptStages`).
- Portability: legacy (service.json is empty until the behaviour moves to catalog ops).
