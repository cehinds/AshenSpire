# Attribute variance module (`attribute-variance@1.0.0`)

Seeded spread for characters whose tags allow it (`character.enemy`): up to `points` points move between the top `among` priorities, never below points set explicitly. The build checks every possible spread can still pay every card. Off: every copy of a character has identical stats.

Turn off from `game.json`: `{ "modules": { "attribute-variance": false } }`.
