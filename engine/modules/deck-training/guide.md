# Deck training module (`deck-training@1.0.0`)

Deck-editing copy limits. `training.basic` (all classes) gives unlimited basic-rank maneuvers and the basic pools; `training.graduate` gives unlimited cantrips. Weapon arts and class specials (`owned`) always count copies owned. Read with `deckCopyLimit()`. Off: every card counts copies owned.

Turn off from `game.json`: `{ "modules": { "deck-training": false } }`.
