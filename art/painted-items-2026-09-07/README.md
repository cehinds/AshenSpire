# Painted item direction — first pass

Built-in image generation produced three isolated transparent illustrations: greatsword, kite shield, and parrying dagger. The PNG masters are preserved here; 512px WebP copies replace the corresponding existing inventory icons. Character-held weapon sprites are separate assets and were not replaced with inventory compositions.

Style: painted steel, weathered brass, dark leather, restrained teal, warm upper-left light, crisp silhouettes, transparent backgrounds. Match the painted armor palette while keeping each weapon type easy to recognize. Avoid primitive low-poly shapes and excessive glow.

The interactive review is /items-preview.html. It uses the production inventory card and detail renderers, actual item definitions and the shared kit CSS. All inventory cards gain artwork thumbnails and detail panels gain larger framed art and spacing. This first pass covers three item illustrations, not the entire equipment catalogue.
