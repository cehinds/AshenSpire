# Low-Poly Fighters — Painted Poses

Painted orthographic reference sheets (5 views: top · right · bottom · left · back)
for the four classes. Served on GitHub Pages at `/docs/low-poly-fighters/`.

`index.html` expects exactly these eight files beside it — drop the sheets in
under these names and nothing else needs to change:

| File | Class | Pieces on the sheet |
|---|---|---|
| `reaver-armour.png` | Reaver | Helmet · Chest · Leg armor · Belt · Cloak |
| `reaver-kit.png` | Reaver | Gauntlets · Arm armor · Boots · Longsword |
| `herald-robes.png` | Herald | Faceted hood · Halo headpiece · Chest mantle · Under-trousers · Cord belt · Layered robe body |
| `herald-kit.png` | Herald | Bell sleeves · Dark gloves · Ankle boots · Prayer-bead rosary · Star mace |
| `rogue-garb.png` | Rogue | Hood · Cowl / shoulder cloak · Chest jerkin · Trousers · Utility belt / tassets |
| `rogue-kit.png` | Rogue | Fingerless gloves · Forearm bracers · Calf boots · Matched daggers |
| `starseer-vestments.png` | Starseer | Crooked hat · Cowl mantle · Tunic · Trousers · Belt tabard |
| `starseer-kit.png` | Starseer | Cloak · Gloves · Sleeve bracers · Boots · Star staff |

Reference only — the game loads its per-piece sprites from `assets/equipment/`, not from here.
