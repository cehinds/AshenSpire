Map route history

ActRouteModel and actRouteStripHtml compose the act title, Entrance, fixed evenly spaced encounter circles and Boss in one desktop row. Saved visits reuse map glyphs, the current position is ringed, and future circles remain empty. The title sits above the rail on phones; inspecting a destination does not change the receipt.

Current integration: mountMap and mountMapBoard render legacy dungeons directly. The adapter supplies geographic node positions, traced polylines and the unchanged paintings; the normal node glyphs, fog knowledge, camera, selection tray, tooltips, legend and keyboard controls are shared. There is no separate dungeon node renderer.

The dungeon map now composes the shared W4b HUD, orientation strip, map frame, Potions, kit Back/Enter buttons and location tray. The shared SVG node artwork keeps markers circular; entrances sit on the approach roads. Smoky dark fog has brown haze restricted to authored road paths.

Legacy dungeon · road exploration

legacyDungeon.js maps 24 authored nodes to connected roads, themed fog, saved decisions and one-time encounters. Its dialogue adapter reuses W4c; combat reuses W4 with the same paired floor/background scene and a dedicated boss arena. Actors remain above both art plates.

Card size

Current shared HUD tuning: portrait scale 70% · primary-row gap 8 px · Quick Access card gap 2 px (1 px on narrow screens) · vital-row gap 2 px. Narrow Quick Access removes panel padding while preserving every control target. Values are data-owned in balance.ui.hudPresentation.

Run-header contract: identity-cluster, centered cinders-counter, and right build-metadata-trail negotiate in one row. Cinders and metadata cap at 30vw; Act/Floor show current values by default, while totals and lower-priority metadata are configurable/progressive.

Quick Menu / overlay contract: Quick Menu uses the stable production caption and resolves absent or invalid preferences to Mirror; legacy off and switcher remain explicit modes. Its groups are Settings / Controls; Fullscreen / Music; Inventory / Character; then Load / Save / Save and Quit / Quit Without Saving. Lifecycle actions confirm destructive unsaved changes. The in-run overlay keeps only Settings and Controls as tabs, with Save Game and Save and Quit in its persistent footer.

Armoury contract: Player labels are Character / Inventory / Hybrid (internal compatibility keys remain grid / rack / hybrid). Armaments, Inventory, Cards, and Stats share the Folding Tray shell. Armaments is non-resizable; resize handles are optional expanded capabilities, and Inventory exposes one only in supporting-tray contexts. Armament rows use complete scaled card thumbnails, compact position/name/state headings and explicit Inspect, Replace and Unequip controls. armamentItem.holdAction is false: first touch opens read-only details, destinations are explicit, and comparison is inline. Other inventory classes retain their authored hold capability. Open the rendered Asset Components reference.
