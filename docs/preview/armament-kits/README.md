# Armament combat kits

Open `armament-kits-preview.html` through the preview server. Choose a class and
either hand from all 25 armaments, then start a fresh fight. The sandbox puts
the equipped item cards in the opening hand, with normal costs and effects.
It uses disposable screenshot-mode storage and does not change ordinary saves.

Try Straight Sword + Round Shield to play a shield Strike beside a sword;
Kite Shield for Guardian and its temporary Exhausting Enter: Bulwark skill;
Tower Shield for Bastion; Spiked Shield for Spiked Reprisal; and Buckler for
Riposte. Empty Hand and staff choices are also available. Use the full-window
fight link on phones. The character-creation link opens the actual setup flow.

Validation covers all 25 items across four classes, all 600 ordered distinct
item pairs, starter budgeting with no filler, permanent removals, saves,
equipment swaps, smithing, two-handed conflicts, and solo/co-op ownership.
The browser probe checks all 25 contribution panels, desktop/tablet/phone
containment, and playing Guardian then Bulwark as a Rogue through real input.
The separate character-creation probe passed 870 checks. The full Node suite
passed 138 tests, with no failures; after integrating the latest dev changes,
the 106 core engine tests, 704 kit cases, and 70 migration regressions also passed.
The kit screenshots and 38 browser checks were refreshed on build 0.6.0.113.
