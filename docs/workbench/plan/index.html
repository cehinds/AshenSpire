Chore/ImproveTooling · tooling consolidation

AshenSpire Workbench Plan

About fifty tools in the repo, in the art repo and from past sessions merge into one desktop Workbench with eight modules. For each module: a wireframe of the planned screen, screenshots of the tools it replaces, and a checklist. Where two tools do the same job, the easier one to use is kept and the other's unique features are added to it.

Phase 0 · in progress

Workbench shell building

One window that opens every tool, with the game running beside it. Saving anything reloads the game.

What it does

    • Status dot per tool, Restart when a tool is down
    • Drag to resize; Desktop, Tablet and Phone sizes
    • Auto-reload on save; recompiles content first when data changed
    • Pop out to its own window, collapse with Ctrl+\
    • A test fails if a new tool page is added but not listed

Replaces

Three launchers and three ports (Content Editor 4317, Pose Studio 4318, UI Studio 4319), and the editor's preview hub. Every root *-preview.html page and docs tool is opened from the Library.
