# Component collection credits

43 new raster master paintings, enemy illustrations, transparent props and parchment material were generated with OpenAI's built-in `image_gen.imagegen` tool for the owner's requested Ashen Spire component extraction. All prompts and reference roles are preserved in **generation.json** and individual **generation/** records. PNG masters remain unchanged; WebP files are format-only exports.

Seventy-one new SVG components and motifs were authored directly in **build-collection.py**. Their visual language was derived from the owner's original twelve concept boards. No third-party icon library, artwork or new font was downloaded. These are first-party generated artwork and original vector geometry; no third-party asset license is claimed for them.

The 194 unchanged first-kit artwork files retain the original kit's provenance. **source-generation.json** preserves its raster prompts. **source-canonical-map.json** records the 49 original canonical copies; their collection paths are prefixed `assets/reused/`. Eight additional canonical objects retain the source paths and hashes recorded in the new manifest. The source credit snapshot is **SOURCE-CREDITS.md**, from the AshenSpire repository, and is not a relicensing grant.

Cinzel, Cormorant Garamond and Inter font copies retain their existing OFL license in **fonts/OFL.txt**. The original concept boards copied into **references/** were first-party generated visual inspiration; their text is illustrative and does not define game rules.

## October 4 canonical motif expansion

Ten opaque desktop/portrait destination paintings extend the existing canonical survey motifs: Old Aqueduct, Drowned Hamlet, Frozen Camp, Caldera Rim and Drowned Orchard. Six independent true-alpha decorations supply Second Cairn fallen/raised sword poses, road signal beacon, caravan medicine strongbox, hanging chain/hooks and open codex/bookstand. Their saved generation records preserve exact prompts, supplied reference roles, source-lore keys, original generator paths and unchanged source hashes.

These are optional scene/inspection layers. Map coordinates, combat floors, NPC identity, inventory/reward types and Cairn choice state still come from canonical runtime content. Recipe options never make either sword pose an automatic gameplay-state receipt.

No new third-party artwork, icon libraries or licenses were introduced. Existing source credits and font licenses remain attached.
