## Reproduce the JS01 identity comparison

Extract source commit `aa79b6d142bb4cf486220ef0dd12d8813d301f19` into a scratch directory, including `engine`, `src`, `tests`, `tools`, `content`, `games` and `package.json`. From the new checkout, run `python docs/qa/verify-js01-identity.py <before-source> . <output-dir>`. The script instruments the existing test scenarios in both trees and compares their raw native replays. It checks 19 current checkpoints and eight save envelopes, and compares the historical replay in full.

The only current differences are the new runtime and profile digests, the two pinned mechanics and starter-deck artifact hashes, the profile opt-in `weaponArtRank: 1` and the single art instance's stored Rank 1. The saved art occurs in the deck, collection, and combat snapshot. The comparison then checks every other raw value exactly after removing the ordinary save timestamp. Run `node --test tests/core2-cleanup-baseline.test.mjs` to verify the shipped module transform returns the same full result as native.
