# Alternative independent source-alpha aura

- This narrow alternative renderer change preserves class artwork, selected stances, authored travel, 260 ms sequences, impact timing, reduced motion and the separate red hit-flash mask.
- The preliminary compiled 1143 native Counter failure remains recorded. Recursive Canvas filter chains delayed the first animation frame; caching the same chains retained an unacceptable cold cost and changed fractional resampling. Those failed controls remain under `D:/repos/.codex/outputs/combat-card-stances/cache-review`.
- Each authored shadow now draws independently from the original image alpha. Resource colors, ordered offsets, numeric blur strengths and brightness are retained; the body draws once. This intentionally produces a thinner outline rather than repeatedly shadowing earlier shadows. Canvas `shadowBlur` and CSS `drop-shadow` are different compositors, so exact old glow pixels are not claimed.
- Each stage uses one reusable 768 × 544 work surface plus its existing visible surface: 3.1875 MiB of RGBA pixels together, excluding the existing hit mask and possible GPU copies. No per-frame surface allocation or filtered-art LRU is needed. Disposal releases the work surface; late artwork completion cannot repaint a disposed stage.
- The original source draws at 512 × 512, including mobile images. Fractional travel remains inside that draw, followed by an integer-position whole-surface copy; the stage boundary clips the final glow. Unsupported future filter grammar preserves the original filter path rather than silently dropping effects.
- The initial action aura is materialized before resetting the animation clock, including when a preceding hurt effect already queued a frame. Restored presentations remain wall-clock based; rendering does not extend an expired action.
- The off-tree eight-case independent-pass control measured cold materialization at 14.6–105.7 ms, compared with up to 3.7 seconds for the nine-shadow recursive chain. These controlled measurements support implementation; they do not establish native game input latency or final compiled acceptance.
- Focused tests cover every authored filter configuration, independent original-alpha shadows, one body and brightness pass, fractional source placement, bounded reuse, fallback, disposal, late loads, queued-frame timing, restoration and unchanged animation behavior. Existing Node and Python protection policies still protect the stage and helper without broad exceptions.
- Actual source-stage cold/warm native interaction and final unmodified compiled Counter proof remain required before acceptance.
