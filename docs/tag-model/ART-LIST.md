# Combat symbol art list

The 56 placeholder combat symbols: each has a tag key, what it is in play, the
icon it borrows now, an art brief, its target size and format, and a priority.
Data: `tables/presentation/combat-symbols.csv`. The `artBrief` and `priority`
columns are set in `tools/build.mjs` and guarded by `tools/check.mjs`.

Counts: 22 P1 (combat-critical), 29 P2 (build or card specific),
5 P3 (card keyword markers). Total 56.

Shown now: what the game draws today, mostly a text glyph. Borrowed icon: the
stand-in the row points at (`assignedAssetRef`), used until the art lands.

Target tiers come from `tables/presentation/resolutions.csv`: the icon category
is SVG 24x24 at light and high (max 256 px); card icons keep the 128x128 of their
folder. Briefs follow the existing marks in `src/content/combatSigils.js`: one
ink (currentColor), no class colour, solid for actions and damage kinds, line
weight for effects, and a 32-unit grid.

Evade stance sprite (owner request, DECISIONS.md section 5): row `evade`,
priority P1. It draws the Defend sigil until its own sprite exists; add an
`assets.csv` id when the art does. Open: one stance sprite for all Evade cards,
or one per card (about 15 in the tree; only Dodge Roll is modelled today).
