# Game structure cleanup plan

Owner's ask (2026-10-24): "clean up the game structure so that I can easily update it, make it human readable."
Owner's decision: both content and code, **content first**, landed as **small PRs** (one area each).

The rule this plan follows: **game content is edited in `content/source/` (JSON or CSV), never in JavaScript.**
`node tools/content-build.mjs` compiles each source file to `src/content/generated/`; the
`src/content/<area>.js` module becomes a two-line re-export that names its source. Design notes
that lived as code comments move to `content/source/CONTENT-NOTES.md`. Every move must leave the
compiled content deep-equal to before; no value, id or order changes.
