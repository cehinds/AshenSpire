# Unranked card templates (owner, 2026-11-21)

Reference shapes for Unranked (combat power <= 0) cards. Printed (authored) numbers.
"Most" means the typical card; outliers are allowed when another cost or drawback pays for them.

| Template | Cost | Damage | Poise | Notes |
|---|---|---|---|---|
| Strike (basic hit) | 1 SP | 6 | 0 | Ordinary hits carry no Poise. |
| Smash | 1 SP | 4 | 2 | Smashes carry intrinsic Poise. |
| Spell, no MP | 1 SP | 3 | 3 | Spells carry intrinsic Poise. |
| Cantrip | mostly 1 SP + 1 MP (0-1 each) | 4-6 | 0-2 | |
| Defend | 1 SP | Block 4 (final) | - | Reaction trait weighs 3. |
| Sweep, Counter | mostly 2 SP | | | |

General: most Unranked damage cards deal 4-6 damage with 0-2 Poise. Poise damage is common only on
smashes and spells.

Weights set with these templates: maneuver:attack/defend/casting 0, maneuver:smash 1, trait:reaction 3.
