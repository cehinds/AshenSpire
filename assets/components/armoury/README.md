# Armoury component references

This folder is the home for Armoury reference screenshots and visual notes.
Component IDs and selectors are authored in
`content/source/armouryUi.json` (`assetComponents`) and documented in
`docs/ASSET-COMPONENTS.md`. Add a reference image here using its registry ID in
the filename, for example `armoury.inventory.item.folded.png`.
