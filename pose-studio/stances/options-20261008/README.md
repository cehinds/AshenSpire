# Stance choice boards — 2026-10-08

Five candidates for each of Attack, Defend and Casting for Reaver, Rogue,
Starseer and Herald: 60 labeled options across 12 paintings.

Open `index.html` through the stance preview server. Each label includes class,
stance and option number. Click a painting to enlarge it; choose an option and
copy the choices into the chat. Browser choices are local review state and do
not change any runtime asset or catalog.

The project owner rejected the first pass's Reaver guard, Rogue's side guard,
Starseer's rear book position and Herald's book orientation. The new generation
prompts specifically require front-facing guard space and books held in front
with their open pages toward their own readers. These are candidates awaiting
selection; no anatomy approval is implied.

Built-in ImageGen creates one comparison painting per class/stance. Source PNGs
are preserved unchanged. CSS displays five candidate viewports from each painting;
the manifest includes wider viewports where needed to retain long staff tips.
labels are native HTML beneath each cell. No bitmap compositing, invented
anatomy, repainting or runtime promotion occurs here. `manifest.json` preserves
the exact prompts, reference paths, cell positions and stable candidate IDs.
`generation-receipts.json` preserves generated source locations and the follow-up
correction prompts used for the final boards.

`selections.json` records the owner's 12 annotated choices for Reaver, Rogue, Starseer and Herald,
with exact source viewports and reference screenshots. Reaver's defending pose
intentionally uses attack option A3. Rogue's attack and preparing selections
retain the original source frames. The confirmed gallery shows these choices
separately from the 60 candidates; runtime exports remain unchanged.

Herald selections: Attack A5, Defend D2, Preparing/Casting C1. All four classes
now have three owner-selected pose identities.
